# 准备 MiniMax TTS 纯口播稿

将内容已经定稿、无需研究或实质性改写的中文科技文案转换为适合 MiniMax 文本转语音的纯口播文本。

## 必读参考

转换任何稿件前，完整阅读 [references/pronunciation-rules.md](references/pronunciation-rules.md)。先应用其中的产品、协议和项目专用规则，再应用通用规则。项目指定读音优先于其他合理读法。

## 工作流程

1. 确认输入和输出。
   - 输入文件默认应为 UTF-8 Markdown 或纯文本。
   - 输入是文件时，在同一目录创建 `源文件基本名（TTS纯口播稿）.md`，其中基本名不包含原扩展名。保留 Markdown 后缀，但文件正文只写可朗读文本和合法停顿标签。
   - 目标文件已存在时使用不冲突的新文件名；只有用户明确要求时才覆盖。
   - 用户指定输出路径时使用该路径；如果该路径与源文件相同，必须先取得明确覆盖授权。
   - 输入是粘贴文本时，只返回口播正文。用户要求转换报告时，将报告放在口播正文之外，不得写入 TTS 文件。

2. 建立内部转换清单。
   - 转换前逐项识别数字、日期、时间、比例、范围、公式、型号、协议、缩写、单位和符号。
   - 在内部记录每个原始单元及其目标读法；这份清单默认不交付。
   - 转换后逐项回查，确认没有漏项、重复项、量级变化、数字丢失或型号串改。

3. 保留原文内容和结构。
   - 保留事实、数字含义、结论、段落顺序、语气、强调重点和论证关系。
   - 不添加事实、例子、笑点、新主张、资料或原文没有的内容性过渡。
   - 只做口播所需的表层调整：修改标点与换气位置，移除不可朗读格式，把理解所必需的标题压缩成中性的口播提示句。

4. 清理不可朗读格式。
   - 移除 Markdown 标题、强调、列表、引用块、代码、链接、网址、脚注标记、资料来源、画面提示和作者备注等格式。
   - 保留链接锚文本、列表正文、引用正文和表格中的必要信息；把它们改写为自然段，不得因删除格式而删除有效事实。
   - 省略只用于排版或制作流程的标题、表格、分隔线和说明。
   - 每段表达一个主要口播要点，段落之间保留一个空行。

5. 规范容易误读的文本。
   - 先按语义分类，再转换数字；不得用一个通用数字转换器处理所有数字。
   - 先应用产品和协议专用读法，再处理通用数量、单位和符号。
   - 按规则拆分需要逐字母朗读的缩写；保留项目实测可连读的品牌词和产品词。
   - 不翻译或重命名产品。遇到规则未覆盖的新型号时，先依据同项目既有稿件和上下文推断。
   - 只有存在两种差异明显且都会改变交付结果的读法时，才询问用户。

6. 添加必要的 MiniMax 停顿。
   - 只使用 `<#x#>`，其中 `x` 为 `0.01` 到 `99.99` 秒，最多两位小数。
   - 停顿标签必须位于两个可朗读文本段之间，不得出现在全文开头或结尾，不得连续使用。
   - 允许把短停顿内联放在句末标点之后，也允许把章节停顿单独成行并置于两个口播段落之间。
   - 根据语义分量决定时长；如果标点和换段已经足够，省略标签。除非用户明确要求，不添加情绪或音效标签。

7. 校验结果。
   - 文件输出完成后运行 `python3 scripts/tts_lint.py <输出文件>`；粘贴文本可通过标准输入运行 `python3 scripts/tts_lint.py -`。
   - 修复每个警告。只有用户明确要求保留相应单元时，才可接受警告，并在 TTS 文件之外说明。
   - lint 只能发现静态格式和常见词形风险，不能证明读法、事实或转换关系正确。
   - 对照源稿重新检查内部转换清单，再从头到尾完整朗读输出，重点检查型号、年份、小数、百分比、范围、单位、缩写和停顿。

## 输出规范

TTS 文件正文或纯口播交付物只能包含应被朗读的文本和合法 MiniMax 停顿标签。

- 默认输出 UTF-8 Markdown 文件，扩展名为 `.md`；正文不使用 Markdown 标题、列表、链接、表格或代码语法。
- 不包含检查清单、资料来源、转换说明、文件路径或制作提示。
- 口播文本中不保留阿拉伯数字；停顿标签内的数字是默认的唯一例外。
- 不保留未处理的计量单位、数学符号、紧凑技术缩写或有歧义的字母数字组合。
- 保留正常中文标点和自然段落。
- 文件路径、lint 结果和用户要求的转换报告只在对话中单独说明。

## 核心约束

- `2026年`、`4.21GHz`、`802.11ax`、`骁龙888` 和 `天玑9500` 必须依据各自语义使用不同读法。
- 天玑型号的项目简化读法不得套用到数量、价格、频率、电池容量、年份或其他型号系列。
- 用户已明确指定读音时保留该读音，但不得借此改变产品名称、事实或数字含义。
