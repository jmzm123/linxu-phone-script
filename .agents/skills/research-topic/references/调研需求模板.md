# 调研需求模板

写到 `调研需求/{选题}-调研需求.md`。整份控制在一页，下面是完整格式，带【】的部分替换掉。

```markdown
# 调研需求：【选题原话】

**时长建议：** 【X分钟左右（约Y字）】
**资料存放：** `调研/【选题】-调研资料.md`

**截至【年月】的最新情况（预查，未核实）：** 【当前最新的机型/芯片/标准/数据是什么，例如"最新 iPhone 是 18 系列"】

**预查看到的情况（未核实）：** 【两三句话：现状是什么；最值得查的疑点在哪；我猜这期最有料的地方是什么】

---

## ⭐ 最重要的3个

1. **【问题】**：【具体要查什么，要什么口径的数字】
2. **【问题】**：【……】
3. **【问题】**：【……】

## 其他

4. 【问题】
5. 【问题】
……（一共10个左右）

**要求：** 关键数字附出处。【这期最容易混淆的地方，例如：官方目标值、试验值、实测值请分开标注】
```

## 写法要点

- 问题里出现的机型、芯片、标准版本，必须是预查确认过的当前最新版本。要求林序查"最新旗舰"时，直接点名是哪几款
- 最重要的3个问题，要能撑起一篇稿子的主线：观众最想知道的答案，加上最容易被误导的那个数字
- 问题要具体到"查哪个数、什么口径"。例如"5G纸面 vs 实测：今天国内5G的实测速度和时延是多少（Ookla、工信部、信通院，最好是2025-2026年）"，不要写成"5G表现如何"
- "其他"里可以放：新能力是什么、普通人能不能感觉到、时间表、要不要换设备、争议、能让观众秒懂的换算
- 不需要"调研目标""交付格式"之类的套话段落
