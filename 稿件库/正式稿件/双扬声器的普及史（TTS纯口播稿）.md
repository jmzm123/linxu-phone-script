二〇一三年，H T C 推出了 One M 七，正面上下两个扬声器，配上专属功放，音量大到可以当蓝牙音箱用。

H T C 把这套系统叫 BoomSound，当时的科技媒体都说，这是安卓手机音质的天花板。

但六年后，H T C 市场份额跌到不足百分之一，几乎从地球上消失。

而双扬声器，却在二〇二〇年之后突然成了千元机的标配。连九百块钱的红米 Note 都开始宣传"立体声双扬"。

这个技术明明二〇一三年就成熟了，为什么要等七年才普及？H T C 做对了技术，为什么反而死了？

大家好，我是陪你聊数码的林序。今天的手机参数说明书，我们聊聊双扬声器背后的故事。

<#1#>

二〇一三年的 H T C，用的是正面双扬声器。听起来很高级，但太占地方。

手机正面就那么大，屏幕要大，额头下巴也要放传感器和按键，H T C 硬是在上下各塞了一条扬声器。结果就是，屏占比上不去，手机显得傻大黑粗。

那个年代，全面屏还没出现，大家比的就是"屏幕更大、边框更窄"。H T C 为了音质牺牲屏占比，用户根本不买账。

更关键的是，二〇一三年的用户还没有"外放需求"。

那时候短视频还没火，抖音要到二〇一六年才上线。大家看视频主要在电脑上，手机就是刷微博、玩游戏，游戏也以单机为主，不需要听声辨位。

你做了一个超前的技术，但用户感知不到价值，那就是白做。

所以 H T C 的悲剧是时机不对。它就像一个在绿皮火车时代造高铁的人，铁轨都没铺好，你跑再快也没用。

<#1#>

真正改变游戏规则的，是二〇一六年的苹果。

二〇一六年九月七日，iPhone 七发布会。苹果宣布取消三点五毫米耳机孔，全场掌声雷动。

库克说这是一个"需要勇气"的决定。但其实苹果更需要勇气去说服用户：你的耳机孔没了，但我给你加了个扬声器。

iPhone 七用的是听筒加底部扬声器的方案，苹果叫它"立体声扬声器系统"，音量是 iPhone 六 S 的两倍。

这个方案比 H T C 聪明在哪？不占额外空间。

听筒本来就在那，苹果只是给它加了功放，让它在横屏时能当左声道。底部扬声器当右声道。成本增加不到两美元，但体验提升肉眼可见。

更重要的是，苹果给了一个"取消耳机孔"的正当理由。你看，我不是单纯砍成本，我是用这个空间给你做了双扬声器。

但当时的安卓厂商，集体冷眼旁观。

小米六、华为 P 十、三星 S 八，清一色单扬声器。大家都在想：苹果取消耳机孔被骂惨了，我们还是别跟。

这一观望，就是两年。

<#1#>

二〇一八年，转折开始出现。

三星 S 九用上了 A K G 调校的双扬声器，魅族十六 T H 主打"吃鸡听声辨位"。但这都是旗舰机，价格三四千起步，普通用户摸不着。

真正的临界点，在二〇二〇年二月。

小米十发布，雷军在发布会上花了整整五分钟讲扬声器。对称式双一二一六超线性扬声器，等效一点零 C C 音腔，七磁发声单元，最大振幅正负零点六五毫米。

小米十 Pro 的外放音质，在 D X O Mark 评测中拿了七十六分，全球第一。

这是小米数字系列全面屏时代后，第一次配双扬声器。小米八、小米九，都是单扬声器。

为什么二〇二〇年突然 all in 了？

供应链产能爬坡，成本降到可控范围。

二〇一八年，瑞声科技推出了 S L S 超线性扬声器技术。核心原理是双音圈对称驱动，解决了传统单音圈在大振幅时的失真问题。

小米十 Pro 全球首发"经典级 S L S"，音质确实提升了。但更关键的是，量产规模上去之后，成本从每颗五到八美元降到了两到三美元。

双扬声器相比单扬声器，B O M 成本只增加一到两美元。对于一台三千块的手机来说，这点成本完全能承受。

二〇二一年，瑞声科技因为这套方案拿了 OPPO 的"最具创新奖"，官方评价是"对手机行业向标准化和立体声方向发展起到推动作用"。

标准化，就是普及的前提。

<#1#>

短视频爆发，外放从"偶尔用"变成"天天用"。

二〇一八年一月，抖音日活还在快速增长期。到二〇二〇年一月，日活突破四亿。快手同期也到了三亿。

二〇二〇年六月的数据显示，短视频用户占网民的百分之八十八点三，人均每天刷抖音九十三分钟，快手八十六分钟。

你想想，每天一个半小时在刷短视频，还有多少人会专门戴耳机？地铁上、食堂里、蹲坑的时候，都是直接外放。

用户的使用场景变了，对外放的需求就从"可有可无"变成了"必须要好"。

游戏市场也在推一把。二〇一九年《和平精英》火了，"听声辨位"成了刚需。你用单扬声器，敌人从左边还是右边来都听不出，那还玩什么。

这时候厂商发现，双扬声器不再是"锦上添花"，而是"不做会被骂"的基础功能。

到二〇二〇年，iPhone 还在用六十赫兹刷新率的屏幕。安卓旗舰早就上了九十赫兹、一百二十赫兹。

但在音质上，iPhone 的双扬声器调校确实好。安卓厂商终于找到一个能跟苹果正面 P K 的参数：对称式双扬。

苹果用的是听筒加底部扬声器，上下音量不均衡，严格来说是"伪双扬"。而小米十用的是上下对称的独立扬声器，音量一致，这是真立体声。

营销文案一写："超越 iPhone 的立体声体验"，用户一听，真的有差距，那就买了。

双扬声器从"旗舰专属"变成"标配功能"。到二〇二一年，连千元机都开始标配。九百块钱的红米 Note 十、一千三百九十九的 realme Q 三、一千四百九十九的 iQOO Z 五，都有双扬声器。

渗透率从二〇一八年的不到百分之二十，飙升到二〇二六年的百分之六十三。

<#1#>

但不是所有厂商都愿意跟。

华为是最典型的"双扬无用论"践行者。

二〇一九年，华为 P 三十和 P 三十 Pro 发布，两台旗舰，全是单扬声器。P 三十 Pro 还用了屏幕发声技术替代传统听筒，但就是不做双扬。

GSMArena 的评测直言不讳："P 三十明明有传统听筒，为什么不做双扬？我们猜测是华为不想让 P 三十比 P 三十 Pro 多一个功能，让 Pro 显得难堪。"

花粉俱乐部用户吐槽："所有的华为手机，音质好的几乎没有吧，好像也没有立体声双扬声器。"

华为的逻辑是什么？他们认为双扬声器"感知不强"，占用内部空间，不如把空间留给电池和影像模组。

这个逻辑在工程上没错，但低估了用户的心理预期。

到了二〇二〇年，小米十、三星 S 二十都在猛吹双扬，华为 Mate 四十还是单扬。用户在对比参数的时候，直接扣分。

B 站有个评测说得很直接："都到这个价位了，上个双扬多好啊。可惜我大华为就是不给。"

O V 系的跟进更慢。

vivo S 系列从 S 十七到 S 十九，长期单扬声器。vivo 社区有用户连续请愿："强烈建议改成双扬声器，不是因为单扬声器的话我早就买了，从 S 十七看到 S 十九，都是单扬。"

OPPO 直到二〇二一年后，瑞声 S L S 方案成熟了，才全面覆盖。

为什么 O V 慢半拍？因为目标用户不同。

O V 的主力用户是年轻女性，购买决策的优先级是拍照、外观、快充。外放音质在决策权重里排不上号。

既然用户不在意，那就晚点跟，先把钱花在刀刃上。

但到了二〇二二年，市场已经被小米和荣耀教育完了。用户看参数的时候，第一眼就看有没有双扬。O V 不跟，就显得"减配"。

这就是路径依赖。当整个市场的预期被拉高之后，你想不跟都不行。

<#1#>

二〇二六年的今天，双扬声器的渗透率是百分之六十三。还有百分之三十七没有双扬的，主要是三类：百元入门机，成本实在压不出来；极致轻薄旗舰，为了五点六毫米厚度砍掉音腔；小屏手机，内部空间不够。

iPhone Air 就是个典型案例。二〇二五年发布，五点六毫米超薄机身，为了塞下 Face I D 和前置摄像头，只能用单扬声器。

苹果官方解释是"顶部空间被占满"，但用户不买账："一万块的手机，连双扬都没有？"

这说明什么？双扬声器已经从"加分项"变成了"不做会被骂"的基础配置。

但标配之后，厂商开始卷新方向。

音腔体积竞赛。宣传话术从"双扬声器"升级到"一点零 C C 超大音腔""一二一六大尺寸单元"。

调音合作。小米找哈曼卡顿，三星找 A K G，连千元机都开始标配杜比全景声。

新技术应用。二〇二六年，红米 K 九十 Pro Max 和 Poco F 八 Ultra 出现了二点一声道，背部加了独立低音单元。vivo X 二百 Ultra 用压电陶瓷扬声器，厚度只有零点三五毫米，可以藏在折叠屏里。

但这里有个反常识的点：双扬声器的"立体声"，其实很有限。

手机上下扬声器间距只有十六厘米，而音频工程的标准是，立体声分离角要大于三十度才有用。手机横屏时勉强达标，但两个声源距离太近，声音在空气中就混了。

波兰音频媒体 Mobismart 说得很直白："当两个声源距离只有三十到四十厘米时，信号到达耳朵前就已经混合，立体声效果越来越弱。"

所以双扬声器最大的提升是响度、低频、和"不会被手挡住"。

你横屏玩游戏，单扬声器在底部，手一握就堵住了。双扬声器上下各一个，怎么握都有声音。这才是用户真正感知到的。

<#1#>

回到最开始的问题：H T C 做对了技术，为什么反而死了？

因为技术从来不是孤立的。

二〇一三年，短视频没火，用户没需求，供应链没规模，成本降不下来。H T C 一个人冲，冲不动。

二〇二〇年，三重结构到位了，小米顺势而为，一炮而红。

这不是小米比 H T C 聪明，而是小米站在了结构的风口上。

技术、用户、供应链、竞争，四个齿轮必须同时咬合，创新才能转化成商业成功。

今天就聊到这里。如果你用手机外放看这条视频，可以在评论区说说你的手机是单扬还是双扬，音质怎么样。
