# 同样是Type-C，为什么速度能差一百多倍

【画面：第1秒】剪刀剪开一根 Type-C 线，断面里只有几根细线；再剪开另一根外观一模一样的线，里面密密麻麻〔视频模型〕

两根一模一样的 Type-C 线，剪开以后，一根里面只有几根线，另一根塞得满满当当。

少掉的那些线，决定了你拷一部电影，是等十几秒，还是等好几分钟。

【画面：拷贝 10GB 视频的进度对比。USB 2.0 约4-5分钟 / USB 10Gbps 约十几秒，标注"理论估算，实际受存储和文件类型影响"】

而你手机盒子里送的那根，大概率就是慢的那一根。

大家好，我是陪你聊数码的林序。本期手机参数说明书，我们来聊聊 Type-C。

## 第一章 插头一样，里面不一样

Type-C 说的只是插头的形状。速度快不快，要看里面走的是哪一代 USB。

【画面：Type-C 母座24针示意图。先高亮中间的 D+/D−（USB 2.0 数据），再高亮两侧的高速差分线（SS TX/RX），最后高亮 VBUS 供电针】

一个 Type-C 口里有24根针。最老的 USB 2.0，传数据只用中间那一组。高速传输要用的，是两边另外几对。

便宜的线，干脆就不接那几对。插头照样是 Type-C，里面跑的是2000年定下来的 USB 2.0。

这种线，多半就在你手机盒子里。

【画面：官网原文截图并排：华为 Mate 80 Pro"标配数据线支持 USB 2.0" / 荣耀 Magic8 Pro"标配数据线支持 USB 2.0" / 小米 17 Max"整机包装盒数据线不支持 USB3 传输" / Apple 支持文档"随附的 USB-C 连接线……以 USB 2 速度传输数据"】

华为、荣耀、小米的旗舰，官网上都写着：手机本身支持 USB 3，盒子里送的线只支持 USB 2.0。苹果也一样，哪怕买的是 Pro，盒子里那根线也只跑 USB 2 的速度。

想跑满速度，线得另外买。

还有的手机更干脆，接口本身就只有 USB 2.0。

【画面：iPhone 15 / 16 / 17 标准版"USB 2（480Mb/s）"vs 同代 Pro"USB 3（10Gb/s）"，出自 Apple 规格页】

iPhone 从15开始换成 Type-C，可15、16、17连着三代标准版，走的都还是 USB 2.0。只有 Pro 给了 USB 3。同一年的两台 iPhone，拷东西理论上能差二十倍。

安卓这边，不少中端机也是这样。

【画面：华为 nova 15 Pro 100W 快充 / iQOO Neo10 120W 快充，数据速率均为 USB 2.0（480Mbps），出自官网参数页】

有的手机能跑一百多瓦快充，传数据还是 USB 2.0。

因为充电快不快，看的是供电线和快充协议，和传数据的速度是两码事。就像家里的水管和网线，水管再粗，网速也不会跟着变快。

所以瓦数大，只能说明充电快。传东西快不快，要看另一个数：每秒能传多少，单位是 Gbps，数字越大越快。

## 第二章 速度是怎么挤出来的

这个数，是怎么一路涨上来的？

【画面：USB 历代速度阶梯：USB 2.0（2000）480Mbps → USB 3.0（2008）5Gbps → USB 3.1 Gen 2（2013）10Gbps → USB 3.2 Gen 2x2（2017）20Gbps → USB4（2019）40Gbps → USB4 2.0（2022）80Gbps；旁边标注"目前手机最高 10Gbps"】

从 USB 2.0 的480兆，到现在最快的80G，二十多年快了一百六十多倍。不过80G是给电脑和硬盘用的，手机目前最快也就10G。

这一百多倍，是一点一点挤出来的。

最早的一次大提速，靠的是另修一条路。

USB 2.0 只有一对数据线，像一条乡间小路，发数据和收数据还得轮流过。

USB 3.0 没去硬拓这条小路，在旁边另修了两条专门跑高速的线，一条只管去，一条只管回。路上的车速一下快了十倍，从480兆到了5G。

开头剪开线看到的那些多出来的线，就是这些高速线。

到了 USB 3.1，线没再加，改成让车跑得更快，还少装废料。

数据在线上跑，不能光发0和1，还得夹带一些记号，让接收端对得上节奏。USB 3.0 有两成的带宽，都花在了这些记号上。

USB 3.1 让信号本身快了一倍，记号又压到了3%左右，速度到了10G。

再往后，工程师盯上了 Type-C 里一直闲着的那组线。

为了正反都能插，Type-C 里其实留了两组高速线。以前不管怎么插，只用得上其中一组，另一组闲着。

USB 3.2 把两组一起用上，到了20G。USB4 再把每一组提速，到了40G。

这也是为什么20G以上的速度，只有两头都是 Type-C 才跑得出来，老的长方形 USB 口没有第二组线。

到了 USB4 2.0，线加不上去了，工程师就在信号本身上想办法：一次多说一点。

以前的信号只有高、低两种状态。就像打灯语，只有亮和灭，打两下，只能拼出4种意思。

USB4 2.0 多加了一个半亮。同样打两下，能拼出9种意思，一次信号装的信息多了一半多。再加上信号又跑快了一点，到了80G。

顺便说一句，电脑上印着闪电标的雷电接口，和 USB4 是一家人，USB4 本来就是在雷电3的基础上做的。区别是，USB4 最低只要求20G，雷电4 保证40G。想要稳，认闪电标。

## 第三章 名字为什么这么乱

说到这，你可能已经被这些名字绕晕了。不怪你，官方自己就改了好几次。

【画面：同一个 5Gbps 的三个名字：USB 3.0（2008）→ USB 3.1 Gen 1（2013）→ USB 3.2 Gen 1（2017）→ 现在的消费者叫法：USB 5Gbps】

同一个5G的速度，先后叫过 USB 3.0、USB 3.1 Gen 1、USB 3.2 Gen 1，一个东西，三个名字。

结果包装上写着 USB 3.2，可能是5G，也可能是20G，中间差了四倍。

后来官方自己也受不了了，改成直接按速度叫：USB 5Gbps、10Gbps、40Gbps。

所以记住一条：认 Gbps，别认3点几。

## 第四章 为什么还给你 USB 2.0

都2026年了，手机厂商为什么还在用二十多年前的 USB 2.0？

最直接的原因是省钱。只接 USB 2.0 的 Type-C 口，针脚少，电路板上也不用走那么多高速线，零件和板子都更便宜。

有的手机，是芯片本身就只带 USB 2.0，想上高速，得再加一颗芯片，占地方、费电，还要多做认证。

厂商也知道，大部分人其实用不上。现在传照片，多数人用微信、隔空投送、网盘，真正插线拷大文件的人不多。

还有一层，高速接口一直是留给贵的型号的。iPhone 三代标准版都没给，想要就得买 Pro。

所以 USB 2.0 对大多数人确实够用。可你要是常拍4K视频，要往电脑里导原片，差距就很明显了。

【画面：Apple 支持社区帖子截图（隐去用户名）："用随附的线约一分钟，换雷电线大约两秒"，1.7GB 视频】

有个 iPhone 用户往电脑里导一段1.7G的视频，用盒子里的线，等了一分钟。换了一根雷电线，两秒。

## 第五章 买线和用线怎么看

最后说说怎么买、怎么用。

先查一下你手机的参数页，看 USB 那一栏写的是 USB 2 还是 USB 3。要是 USB 2，换什么线都没用。

【画面：USB-IF 认证标志示例"CERTIFIED USB 10Gbps"与功率标"60W / 240W"，速度和功率分开标注】

是 USB 3 的话，再去买线。包装上看数据速度，认准5Gbps、10Gbps这样的数字，有官方认证标志更稳。只写了多少瓦、没写速度的，传数据基本只有 USB 2.0 的速度。线上什么都没印的，也按慢的算。

线也别买太长。速度越高，线能做的长度越短，想跑满，一两米以内就够了。

拷得慢的时候，就看看是谁拖了后腿。手机、线、电脑，三样里最慢的那个说了算。

Type-C 统一的只是插头，里面跑多快，还得自己看清楚。
