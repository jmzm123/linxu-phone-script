## 两期内容

| | 第1期 | 第2期 |
| --- | --- | --- |
| **讲哪张图** | 能效曲线 | 游戏帧率表 |
| **标题** | 看懂极客湾①：一张能效曲线，就能看出新手机烫不烫（10-01 已定） | 看懂极客湾②：几台手机都跑满60帧，差距藏在哪？（暂定） |
| **选题分** | 18 / 20 | 17 / 20（暂估） |
| **一句话结论** | 能效曲线要看同样功耗下谁更高，日常用得最多的是左边低功耗那一段 | 平均帧只是第一格，1% Low、功耗、温度才看得出谁更稳、更凉、更省电 |
| **前60秒的料** | 原神里几台旗舰都跑满 60 帧左右，iPhone 18 Pro Max 3.4W，天玑9500 的 iQOO 15T 4.8W | 同一张表里平均帧几乎一样，功耗和机身温度差出一截；有的机器跑到后半段会掉帧 |
| **观众收获** | 10 秒读懂一张能效曲线：先看坐标轴，再看左边那一段，最后看自己常用的功耗区间 | 看游戏测试先对齐分辨率和测试时长，再依次看 1% Low、功耗、温度 |

## 继续做的判断标准

对照账号基线（3 分钟以上视频中位数，见`复盘表.md`）：

| 指标 | 基线 | 系列的目标 |
| --- | --- | --- |
| 播放 | 32.7 万 | 至少一期超过 |
| 2s 跳出 | 28.4% | 低于基线 |
| 收藏率 | 0.42% | 高于基线（"怎么看"类应该能到 0.7% 以上） |
| 粉/万 | 17.5 | 高于基线（系列的意义就在涨粉） |

- **继续做**：至少一期播放超过 32.7 万，或者两期的收藏率和粉/万都高于基线
- **调整后再试**：播放低但收藏、涨粉高。说明内容有用、标题或开头没留住人，下期先改标题和开头
- **停**：两期播放、收藏、涨粉都低于基线
- 第2期评论区"扣 1"的数量也一起参考

如果继续，后续顺序是：③ 续航测试（mAh 和 Wh）→ ④ 跑分柱状图（常温 vs 液氮、工程机）→ ⑤ 温升曲线与封装。第4期和《跑分高一倍的手机，为什么用起来不一定更顺》有重叠，要隔开发。
