# 林序数码科普视频稿写作工作流程

## 博主信息
- 博主名：陪你聊数码的林序
- 系列名：手机参数说明书
- 平台：抖音
- 内容定位：手机数码科普

## 王骁写作风格核心要素

### 一、开头设计（前30秒至关重要）
**核心原则：制造反差、悬念或冲击**

1. **反差型开头**
   - 模式：看似A，实际是B
   - 例：韩国总统够危险了吧？但是在我们今天要讲的这个地方...
   - 数码应用：大家都说这功能没用，但它其实能救命

2. **具体案例引入**
   - 用一个形象的人物/事件作为钩子
   - 例：刚果金球迷米歇尔穿着彩色西装站成雕塑
   - 数码应用：某个用户因为不懂参数买错手机的真实案例

3. **直击痛点**
   - 立刻抛出观众关心的核心矛盾
   - 例：家里有矿，矿上有贼
   - 数码应用：为什么你的手机总是不够用？

4. **固定开场白**
   - "大家好，我是陪你聊数码的林序"
   - 简短说明本期主题

### 二、内容结构设计

**章节划分法（适合4分钟以上视频）**
- 第一章、第二章、第三章明确分段
- 章节标题要简洁有力、有画面感
- 例：请客，斩首，收下当狗 / 站队，躺平，吃软饭

**数码科普改编：**
- 第一章：这参数是什么
- 第二章：为什么厂商这么设计
- 第三章：你该怎么选

**递进式结构（短视频1-4分钟）**
- 开头抛问题 → 解释原理 → 给出建议 → 总结金句

### 三、叙事风格要点

1. **讲故事，不念参数**
   - 不是：刷新率是屏幕每秒刷新次数
   - 而是：你玩游戏的时候，为什么别人的画面丝滑如德芙，你的像PPT翻页？

2. **大量使用类比和数据对比**
   - 王骁常用：相当于X个海南岛，约等于X个海南省
   - 数码应用：这块电池容量，相当于可以连续刷抖音X小时

3. **保持口语化和网络流行语**
   - 抽象、天降猛男、搞笑称呼
   - 数码应用：性能怪兽、真香、绝绝子（适度使用，不要过度）

4. **强调因果关系和底层逻辑**
   - 不只讲是什么，要讲为什么
   - 揭示"结构性问题"和"路径依赖"
   - 数码应用：为什么厂商要这么设计？背后的成本和技术权衡是什么？

5. **保持专业性与趣味性平衡**
   - 有专业数据支撑
   - 但用生动语言表达
   - 既严肃又幽默

### 四、金句和重复使用的话术

**王骁固定结尾模板：**
```
好了，我们的电子地图册又在XX板块点亮了一个地方，希望我们可以一起学习，
超越情绪，找到看世界的角度，用一种更加理性乐观的态度去拥抱多极化的世界。

今天就聊到这里，如果你有更多的研究资料...非常期待您可以在评论区补充干货和故事，
有了更多的干货评论，才能让我们的节目更加完整。

祝大家变得更强，我们下周再见！
```

**林序数码版结尾模板：**
```
好了，希望这期内容能帮你在选手机时少走弯路，看懂参数背后的门道。

如果你在使用中有什么独特的体验，或者想了解哪个参数，欢迎在评论区告诉我，
你们的反馈能让这个系列更完整。

欢迎新朋友点个关注老朋友点个赞，我们下期再见！
```

### 五、内容深度控制

**1分钟短视频：**
- 一个痛点 + 一个解决方案
- 开门见山，快速给答案
- 结构：问题（10秒）→ 原理（30秒）→ 建议（15秒）→ 金句（5秒）

**2-4分钟视频：**
- 可以讲2-3个相关参数
- 有简单的历史演变或对比
- 结构：引入（30秒）→ 展开（2分钟）→ 建议（1分钟）→ 结尾（30秒）

**4-8分钟视频：**
- 深度拆解一个参数或系统
- 包含历史、技术原理、对比、选购建议
- 采用章节结构
- 可以有争议性观点

**8分钟以上：**
- 专题系列，如"处理器的前世今生"
- 多角度、多层次解析
- 章节清晰，有小标题

## 写稿完整工作流程

### 阶段一：确定选题（与林序沟通）

**输入形式：**
林序可能会给：
1. 一个标题（如"为什么旗舰机都用OLED屏幕"）
2. 一个方向（如"讲讲快充技术"）
3. 一个参数（如"内存和储存的区别"）

**AI的任务：**
1. 如果只是方向，帮助细化为3-5个可选标题
2. 每个标题给出切入角度建议
3. 预判这个选题的受众兴趣点
4. 提示可能的争议点或容易混淆的地方

**输出：**
- 3个标题选项（带简要切入角度）
- 推荐理由
- 等待林序确认

### 阶段二：调研学习（AI自主调研 + 林序确认）

**核心原则：AI主动调研，林序提供市场视角**

#### 第一步：AI自主调研（必须完成）

**使用联网搜索（Tavily MCP）调研以下内容：**

1. **技术原理和演变历史**
   - 这个参数/技术是什么？基本原理？
   - 历史上如何演变的？关键节点有哪些？
   - 为什么会出现这个技术？解决了什么问题？

2. **当前技术现状**
   - 最新的旗舰机型号和主流参数（如iPhone 17系列、小米15、OPPO Find X8等）
   - 当前的技术标准（如传感器尺寸、光圈值、像素数的主流水平）
   - 各家厂商的最新方案对比

3. **供应链和成本**
   - 主要供应商有哪些？（如索尼、三星、豪威的传感器）
   - 技术成本趋势（越来越贵还是越来越便宜？）
   - 量产情况和良率问题

4. **行业趋势和争议**
   - 最新的技术趋势（如"去一英寸化"、"计算摄影"）
   - 行业内的争议点（如"像素越高越好"的争论）
   - 有趣的技术突破或翻车案例

**AI调研输出格式：**
整理成结构化笔记，包含：
- 核心技术原理（用1-2句话说清）
- 关键时间线（2-3个重要节点）
- 厂商方案对比表（列出3-5家主流厂商的做法）
- 争议点和误区（2-3个常见误解）
- 有故事性的案例（1-2个）

#### 第二步：向林序确认（仅确认必要信息）

**⚠️ 只问林序这些问题（避免全盘依赖）：**

1. **市场感知确认**
   - "根据我的调研，现在主流旗舰是[列出型号]，参数标准是[具体数值]。这些信息准确吗？有没有我遗漏的重要机型？"
   
2. **受众痛点确认**
   - "我了解到用户常见的误区是[列出2-3个]。你在抖音评论区看到的用户困惑是这些吗？还有其他高频问题吗？"

3. **内容角度确认**
   - "我计划从[角度A/角度B/角度C]切入。你觉得哪个角度更符合抖音观众的兴趣？"

**格式示例：**
```
林序你好，我已经完成了[参数名]的技术调研，整理了以下信息：

【技术现状】
- 当前主流旗舰：iPhone 17 Pro、小米15 Ultra、OPPO Find X8 Pro
- 主流参数标准：传感器1/1.3英寸、光圈F1.4、像素5000万
- 技术趋势：从堆像素转向提升单像素面积

【用户误区】
1. 以为像素越高越好
2. 不知道传感器尺寸比像素更重要
3. 忽略了镜头光圈的作用

【可讲的案例】
- 小米14 Ultra用1英寸大底的选择
- iPhone坚持1200万像素的逻辑
- 某些手机2亿像素实际表现不如5000万的原因

请你帮我确认：
1. 这些型号和参数是最新的吗？有遗漏吗？
2. 抖音评论区用户最困惑的是哪几点？
3. 你觉得从"为什么iPhone不堆像素"这个角度切入，观众会感兴趣吗？
```

#### 第三步：补充调研（如果需要）

根据林序的反馈，针对性地补充调研：
- 林序提到了新机型 → 立刻搜索该机型的参数
- 林序指出了新的用户痛点 → 调研这个痛点的技术背景
- 林序建议了新角度 → 围绕这个角度找案例和数据

**最终输出：**
- 完整的调研笔记（技术+市场+案例）
- 确认过的最新信息
- 标注哪些适合深入讲，哪些适合一笔带过

### 阶段三：确定视频时长（与林序沟通）

**询问林序：**
"根据这个选题，我建议做X分钟的视频，因为[理由]。您这次想做多长的？"

**时长选项：**
- 1分钟左右（快速解惑型）
- 2-4分钟（标准科普型）
- 4-8分钟（深度拆解型）
- 8分钟以上（专题系列型）

### 阶段四：写稿（AI核心工作）

**写作前准备：**
1. 重新阅读王骁的1-2篇文案，找感觉
2. 阅读示例稿件（`示例稿件-屏幕刷新率.md`），对标结构和风格
3. 明确本期的核心观点（一句话说清）
4. 设计开头钩子（用反差/悬念/案例）
5. **快速过一遍质量清单（`写稿质量自检清单.md`），规划要达成的要点：**
   - 开头用什么钩子？
   - 要讲几个案例？
   - 准备哪些类比？
   - 结构性分析的切入点是什么？

⚠️ **林序禁用句式（重要！）：**
- ❌ **禁止使用"不是...而是..."句式**
- ✅ 改用其他对比方式：
  - "表面看是X，实际是Y"
  - "大家以为X，真相是Y"
  - "听起来像X，本质是Y"
  - 直接说："真正的原因是..."

**写作过程：**

**开头（30秒-1分钟）：**
- 设计钩子，吸引注意
- 抛出核心问题或矛盾
- 自我介绍
- 简短说明本期内容

**正文（根据时长调整）：**
- 用讲故事的方式展开
- 穿插数据、案例、类比
- 避免单纯念概念
- 保持节奏感，不要拖沓
- 适时用反问、设问推进

**结尾（30秒）：**
- 总结核心观点
- 给出实用建议
- 固定结尾话术
- 引导互动

**语言风格检查清单：**
- [ ] 是否用讲故事的方式而非念参数？
- [ ] 是否有足够的类比让小白也能懂？
- [ ] 是否有具体数据支撑？
- [ ] 是否解释了"为什么"而非只说"是什么"？
- [ ] 是否适度使用了口语化表达？
- [ ] 是否避免了过于专业的术语？（或有解释）
- [ ] 节奏是否流畅，有没有拖沓的地方？
- [ ] **是否避免了"不是...而是..."这种句式？**（林序禁用）

**写完初稿后：自检流程**

1. **立即自检（写完初稿的第一时间）**
   - 使用`写稿质量自检清单.md`完整过一遍
   - 逐项打分（1-5分），标注弱项
   - 重点关注致命问题：
     - 开头是否足够吸引人？（前3秒）
     - 是否有结构性分析？（不只讲现象）
     - 技术是否准确？（不能有错误）
     - 是否有实用建议？（观众能照着选）

2. **针对性修改**
   - 优先修复低于3分的项目
   - 强化4分项，争取达到5分
   - 如果总分低于70分，考虑大幅改写

3. **修改后复检**
   - 再过一遍清单，确保总分≥85分
   - 大声读一遍，检查口播流畅度
   - 确认时长控制在目标范围内（±30秒）

### 阶段五：交付与迭代

**交付给林序：**
1. 完整稿件（标注预估时长）
2. 重点说明：
   - 本期的核心观点
   - 开头设计的思路
   - 可能需要配合的画面建议
3. 可选的调整方向

**根据反馈修改：**
- 林序可能要求调整语气、删减内容、增加某部分
- 快速迭代，保持王骁风格的一致性

## 注意事项

### 林序的定位差异
虽然学习王骁的风格，但要记住：
- **王骁讲的是：**地缘政治、国际关系、历史人文
- **林序讲的是：**手机数码、技术参数、选购建议

**因此改编要点：**
1. 王骁的"列强博弈" → 林序的"厂商竞争"
2. 王骁的"历史渊源" → 林序的"技术演进"
3. 王骁的"结构性问题" → 林序的"技术瓶颈/成本权衡"
4. 王骁的"地缘政治" → 林序的"供应链/市场策略"

### 观众差异
- 王骁的观众：对世界局势感兴趣的中高知识水平群体
- 林序的观众：想买手机但看不懂参数的普通消费者

**因此：**
- 要更加通俗易懂
- 更加贴近实际使用场景
- 更多"你应该这样选"的实用建议

### 抖音平台特点
- 前3秒至关重要
- 画面配合文字很重要（AI写稿时可标注画面建议）
- 节奏要快，不能拖沓
- 适度使用网络流行语，但不过度

### 禁用句式和格式
- ❌ **禁止使用"不是...而是..."句式**
- 这是林序明确要求避免的表达方式
- 改用其他方式表达对比或转折

### 避免机械化格式
- ❌ **不要在正式稿件中标注时间轴**（如"0:00-0:45，约45秒"）
- ❌ **不要用"选购建议："这种固定小标题**
- 建议要自然融入正文，用口语化的过渡
- 例如："所以你选手机的时候..."、"记住这一点..."、"如果你是XX用户..."

## 常用话术模板库

### 开头话术
1. "你是不是也遇到过这种情况..."
2. "同样是旗舰机，为什么价格差这么多？"
3. "手机店员不会告诉你的秘密..."
4. "很多人都搞错了..."
5. "花了五千块买手机，却发现..."

### 过渡话术
1. "那么问题来了..."
2. "这就要从XX说起..."
3. "咱们接着往下看..."
4. "更关键的是..."
5. "但这还不是全部..."

### 解释话术
1. "简单来说..."
2. "打个比方..."
3. "你可以理解为..."
4. "换句话说..."
5. "具体到日常使用..."

### 建议话术
1. "如果你是XX用户，我建议..."
2. "这个参数适合XX人群..."
3. "记住这一点就够了..."
4. "选购时重点看..."
5. "避坑指南..."

3. ✅ 至少有2-3个类比或案例

## 示例对比

### ❌ 传统科普写法
"屏幕刷新率是指屏幕每秒刷新的次数，单位是Hz。60Hz表示每秒刷新60次，120Hz表示每秒刷新120次。刷新率越高，画面越流畅。"

### ✅ 王骁风格改编
"你玩游戏的时候，为什么有些人的画面丝滑如德芙，你的却像PPT翻页？秘密就在刷新率。

这就好比放电影，以前的老电影一秒24帧，你仔细看会有点卡顿感。现在的高刷屏幕，一秒能给你刷120帧画面，那感觉就像从绿皮火车升级到高铁。

但是！这里有个厂商不会告诉你的秘密。不是所有120Hz都是真120Hz..."

## 最后提醒

1. **每次写稿前，先读一篇王骁的文案找感觉**
2. **林序是一知半解的数码爱好者，AI要帮他弄懂再用简单的话讲出来**
3. **林序能把控方向和受众，相信他的判断**
4. **抖音观众爱看什么，比绝对的专业性更重要**
5. **保持真诚，不要为了吸引眼球而误导观众**
