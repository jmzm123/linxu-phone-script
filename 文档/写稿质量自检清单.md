# 写稿质量自检清单

使用说明：每次写完稿子，逐条检查。每项打分1-5分，总分70分以上为合格，85分以上为优秀。

---

## 一、开头吸引力（10分）

### 1. 钩子设计（5分）
- [ ] 5分：开头3秒就有强烈的反差/悬念/冲击，让人必须看下去
- [ ] 4分：有吸引力，但不够强烈
- [ ] 3分：平淡但还算有趣
- [ ] 2分：普通开场，容易划走
- [ ] 1分：无聊的定义式开头

**检查点：**
- 是否用了反差/悬念/案例/痛点中的至少一种？
- 开头3秒能否让陌生观众停下来？
- 是否避免了"今天我们来讲XX"这种无聊开场？

---

### 2. 核心问题抛出（5分）
- [ ] 5分：30秒内明确告诉观众"今天解决什么问题"
- [ ] 4分：40秒内说清楚
- [ ] 3分：1分钟内说清楚
- [ ] 2分：问题模糊，观众不知道要讲什么
- [ ] 1分：没有明确的核心问题

---

## 二、王骁风格还原度（25分）

### 3. 结构性分析（10分）
- [ ] 10分：深入揭示了问题背后的结构性原因（成本-技术-市场-竞争的博弈）
- [ ] 8分：有结构分析，但深度不够
- [ ] 6分：提到了多方因素，但没有串成结构
- [ ] 4分：只讲了表面原因
- [ ] 2分：没有分析原因，只描述现象

**检查点：**
- 是否回答了"为什么所有厂商都这么做"而不只是"某个厂商这么做"？
- 是否分析了用户-厂商-供应链-竞争对手的多方博弈？
- 是否指出了路径依赖或结构性困境？

---

### 4. 叙事性（8分）
- [ ] 8分：用讲故事的方式，有人物/事件/时间线，像看纪录片
- [ ] 6分：有一定故事性，但部分地方还是在念参数
- [ ] 4分：偶尔有故事感，但大部分是平铺直叙
- [ ] 2分：完全是教科书式的参数讲解

**检查点：**
- 是否有具体的人物/公司/事件作为叙事锚点？
- 是否有时间线推进感？
- 是否避免了"XXX是指XXX"这种定义式表达？

---

### 5. 章节结构（7分）
- [ ] 7分：清晰的章节划分，每章有小标题，逻辑递进清晰
- [ ] 5分：有章节，但划分不够清晰
- [ ] 3分：只是段落，没有明确的章节感
- [ ] 1分：一团混乱，没有结构

**检查点：**
- 4分钟以上视频是否有章节划分？
- 章节标题是否简洁有力（4-8字）？
- 各章节之间是否有逻辑关系？

---

## 三、语言风格（20分）

### 6. 口语化程度（5分）
- [ ] 5分：完全口语化，像朋友聊天，适合直接口播
- [ ] 4分：大部分口语化，少数地方略书面
- [ ] 3分：半口语半书面
- [ ] 2分：明显的书面语，读起来拗口
- [ ] 1分：学术论文风格

**检查点：**
- 大声读一遍，是否顺畅自然？
- 是否使用了"你想啊"、"结果呢"、"这就尴尬了"这类口语过渡？
- 是否避免了长难句？

---

### 7. 类比和比喻（5分）
- [ ] 5分：每个难懂的概念都有生动的类比，小白也能秒懂
- [ ] 4分：有几个不错的类比
- [ ] 3分：有类比但不够生动
- [ ] 2分：类比很少或不恰当
- [ ] 1分：没有类比，全是专业术语

**检查点：**
- 是否至少有2-3个类比？
- 类比是否贴近生活（绿皮火车vs高铁、筛子、水管这类）？
- 是否避免了用一个专业术语解释另一个专业术语？

---

### 8. 数据和案例（5分）
- [ ] 5分：有具体数字、时间、公司、产品作为支撑，可信度高
- [ ] 4分：有一些数据，但不够详实
- [ ] 3分：偶尔提到数据
- [ ] 2分：基本没有数据支撑
- [ ] 1分：空洞的观点堆砌

**检查点：**
- 是否有具体的数字（时间、成本、销量、市场份额）？
- 是否点名了具体的公司、产品、事件？
- 数据来源是否可靠（不能瞎编）？

---

### 9. 网络用语和幽默（5分）
- [ ] 5分：适度使用网络梗，增加趣味但不过度
- [ ] 4分：有一些幽默点
- [ ] 3分：比较正经，缺少轻松感
- [ ] 2分：过度使用网络梗，显得油腻
- [ ] 1分：要么完全没有，要么尬梗满天飞

**检查点：**
- 是否适度使用了"真香"、"血亏"、"翻车"这类词汇？
- 是否有1-2处让人会心一笑的点？
- 是否避免了过度meme化？

---

## 四、内容实用性（20分）

### 10. 深度和准确性（10分）
- [ ] 10分：技术原理准确，深度够，但不枯燥
- [ ] 8分：基本准确，深度尚可
- [ ] 6分：浅尝辄止，缺少深度
- [ ] 4分：有明显的技术性错误
- [ ] 2分：误导性内容

**检查点：**
- 技术原理是否准确？（不确定的要查证）
- 是否讲清楚了"为什么"而不只是"是什么"？
- 是否避免了过度简化导致的错误？

---

### 11. 实用建议（10分）
- [ ] 10分：给出了明确的选购/使用建议，观众看完知道怎么做
- [ ] 8分：有建议，但不够具体
- [ ] 6分：建议比较模糊
- [ ] 4分：只讲知识，没有建议
- [ ] 2分：建议明显不合理

**检查点：**
- 是否有"如果你是XX用户，建议XX"这样的具体指导？
- 是否针对不同使用场景给出了差异化建议？
- 建议是否可执行（不是废话）？

---

## 五、视频制作适配（10分）

### 12. 画面标注（5分）
- [ ] 5分：关键节点都有【画面：XXX】标注，kimi能直接用
- [ ] 4分：大部分有标注
- [ ] 3分：少量标注
- [ ] 2分：几乎没有
- [ ] 1分：完全没有

---

### 13. 节奏控制（5分）
- [ ] 5分：时长控制精准，没有拖沓，节奏紧凑
- [ ] 4分：略有拖沓，但可接受
- [ ] 3分：明显的节奏问题
- [ ] 2分：大段无意义的重复
- [ ] 1分：时长失控

**检查点：**
- 是否符合目标时长（±30秒）？
- 是否有冗余重复的段落？
- 是否有明显的"水分"？

---

## 六、结尾和互动（10分）

### 14. 结尾总结（5分）
- [ ] 5分：简洁有力的总结，金句收尾，余韵悠长
- [ ] 4分：总结清晰
- [ ] 3分：总结平淡
- [ ] 2分：虎头蛇尾，草草收场
- [ ] 1分：没有总结

---

### 15. 互动引导（5分）
- [ ] 5分：自然地引导评论、点赞，并埋下了讨论点
- [ ] 4分：有互动引导
- [ ] 3分：生硬的"三连"呼吁
- [ ] 2分：没有互动设计
- [ ] 1分：忘记了结尾话术

**检查点：**
- 是否有固定的结尾话术？
- 是否引导了评论区讨论（提问或邀请分享经验）？
- 是否预告了下期内容？

---

## 七、整体评分

**总分：______ / 100**

**评级标准：**
- 90-100分：优秀，可以直接交付
- 80-89分：良好，小幅修改后可用
- 70-79分：合格，需要针对性修改
- 60-69分：勉强及格，需要大幅改进
- 60分以下：不合格，需要重写

---

## 八、快速诊断（重点问题）

如果总分不理想，优先检查这些致命问题：

**致命问题1：开头不吸引人**
→ 前3秒观众会划走，后面再好也没用

**致命问题2：只念参数，没有故事**
→ 失去了王骁风格的灵魂

**致命问题3：没有结构性分析**
→ 和普通科普没区别

**致命问题4：技术错误**
→ 失去信任度，评论区会被骂

**致命问题5：没有实用建议**
→ 观众看完不知道该怎么选

---

## 使用建议

1. **写作过程中**：随时参考，避免偏离方向
2. **写完初稿后**：完整过一遍清单，找出弱点
3. **修改完成后**：再过一遍，确保达标
4. **交付前**：至少要85分以上

**记住：这个清单不是教条，而是工具。如果某些点不适合你的内容，可以灵活调整。但核心的王骁风格要素（结构性分析、叙事性、实用建议）必须保证。**
