# 王骁写法

从 `参考资料/01-07` 七篇王骁原稿里拆出来的思维、架构和语言，写稿时照这里学。每条后面是原文例子，→ 后面是林序这边怎么用。和写稿规约冲突时以规约为准，不学的见规约「禁用」。

## 一、思维：怎么分析

1. **一期一个核心矛盾。** 先找「按理说该 A，结果却 B」，整期都在解它。
   - 马拉维：淡水湖占国土五分之一，最大的问题竟然是粮食不稳。「那我们今天，就以这个问题为目标」
   - 喀麦隆：250 多个民族、英法两套殖民遗产，却「乱不爆、穷不垮」
   - → 快充功率翻倍，充满却没快一倍；内存翻倍，还是不够用
2. **结构大于个人。** 「我们每次节目，总是在强调结构结构结构。没有国家是一张白纸」。现象先从约束找原因：地理（匈牙利「它很多执念，都写在地理里」）、历史惯性、利益格局。
   - → 物理和工程约束、成本、供应链、标准、兼容包袱。「它的毛病，都写在物理里」
3. **问每个角色要什么。** 「法国对当地就两个需求，第一听话，减少沟通成本；第二稳定，降低生产成本。而代比就是抓住了这两条。」
   - → 手机厂、芯片厂、运营商、标准联盟、苹果，各自要什么、怕什么，参数就是它们讨价还价的结果
4. **找一个在历史里反复出现的母题。** 匈牙利的「既要又要」从 1222 年《金玺诏书》一路演到 2026 年大选，最后一句「匈牙利再次重复了自己的历史」。
   - → 同一个取舍每一代都重演：厚度和电池、跑分和发热、新标准和老设备兼容
5. **先承认，再批评，不给单一原因。** 「今天看欧尔班，不能只说他务实，也不能只说他威权腐败。首先要承认……至于他后来为什么越走越偏，那一定不是单一原因，而是个人利益、路径依赖、历史惯性和国际环境变化一起作用的结果。」
6. **证据分级说话。** 有实锤直接说；只有时间线就摆时间线：「我们不能直接下定论……但是这个就是时间表和事情发生的一个因果」；推测先打招呼：「我们说一种可能性」；流行说法逐条找证据，找不到就说找不到（冈比亚「个人观点」章）。「不要看政客怎么说，要看怎么做。」
   - → 不看发布会怎么说，看实测怎么跑
7. **接住观众的焦虑再拆。** 「很多朋友会焦虑。逻辑很简单：……那么会不会……？」然后分政治、承诺、基本面一层层拆。
8. **数字换成熟悉的尺子，再找参照组。** 「234.4 万平方公里，相当于 70 个海南岛」「GDP 相当于四分之一个上海」「东西长 480 公里，相当于从上海到合肥」。汽车出口国内增加值：匈牙利 31%、捷克 50%、德国 74%，然后一句「工厂来了，但是钱没来」。
9. **落到「和我们有什么关系」。** 「一部手机需要 6.5 克钴」；霍尔木兹受阻，「中国司机加满一箱油要多出几十甚至几百块」。→ 落到你买手机、用手机
10. **结尾推演未来。** 「所以我们可以推演一种假设……要么……要么……」。→ 下一代会怎样、什么会打破现状

## 二、架构

**片头**：奇人奇事 → 拉到大问题 → 抛出矛盾 → 当下新闻 → 自我介绍。
- 刚果金：世界杯上一动不动的「雕塑球迷」→ 他扮演的是国父卢蒙巴 →「在球场上守住了比分，但是没能守住国家的战场」→ 铜钴锂镍 → 资源反成诅咒 → 5 月埃博拉 → 自我介绍
- 喀麦隆：92 岁总统连任，27 岁女儿「LV 包挂 Labubu」跳反 →「背后是一个在变局时代中寻找出路的中非国家」
- 开头的人物要具体、细节要荒诞，一句话就能让人想看下去

**档案卡**：自我介绍后一小段交代「这是个什么东西」，数字全换成熟悉的尺子。→ 林序这边压到两三句

**三幕正文**（王骁每期三章，林序 4-8 分钟同样分三到五章）：
1. 来历：地理或起源决定了什么 → 原理、物理约束、最初的路线选择
2. 演化：几代人怎么折腾，母题怎么重演 → 技术迭代、厂商博弈、路径依赖
3. 当下与推演：现在的格局、和我们的关系、接下来会怎样 → 现在怎么选、未来一两年会怎样

**章名**：四字对仗或一句梗，自带态度。
- 「家里有矿，矿上有贼」「请客，斩首，收下当狗」「站队，躺平，吃软饭」「穷版韩国模式」「丰田皮卡打赢卡大佐的坦克」「考公引发的血仇」

**章尾抛问题接下一章**：「继承了父亲的权力和危机，卡卡能坐稳他二世皇帝的大位吗？」「接下来，我们就来聊欧尔班的 20 年。」

**章内三拍循环**：讲几段事 → 一句短判断收住 → 一个设问推到下一段。
- 判断句：「成也冷战，败也冷战。」「送走了白魔鬼，迎来了黑魔鬼。」「一个魔王走了，迎来了一群小鬼。」
- 设问：「成绩这么牛，为什么欧尔班垮了？」「魔王走了，你以为刚果金的好日子就要来了吗，并不是。」「那么问题来了……」

**有名目的列举**：每一项先给个名字再展开。「第一招，靠法国人。」「第二招，靠部落。」「第三招，由部落基础引申出来，靠结婚。」

**结尾**：一句话把母题收住（「匹夫无罪怀璧其罪」「后任给前任擦屁股，前任给后任埋雷」）→ 推演或唏嘘 → 请评论区补一线经验 → 固定话术。观点多时可以单开一章「个人观点」。

## 三、语言

1. **说书腔混网络梗、毒舌。** 乍得一整期用章回体：「话说乍得既得独立」「可谓是：皮卡飞驰破敌阵，枭雄得志定乾坤」；同一期里又有「打不过就加入」「嘎巴一下，死了」。常用梗：抽象人、天降猛男、爆金币、跳反、被扬了、脑子抽抽、「用脚后跟想都知道」「不出意外的话就是没出意外」。
2. **用中国人熟悉的历史和段子打比方。** 刚果版太平天国、「丰田大将当总统，相当于年羹尧当皇帝」、唐末军镇、罗兰大学「相当于匈牙利清北」、首府用殖民大臣命名「约等于我在知识区做内容，知识区就命名为小王区」。
3. **动词狠、有画面。** 撵得嗷嗷叫、轮番爆破、一次性打穿、彻底干碎、杀良冒功。
4. **把国家和机构当人写。** 「法国作为曾经的殖民帝国，肉体瓦解精神不死」「布鲁塞尔脑子抽抽」。
5. **重复出节奏。** 「球队进球，他不动，球队焦灼，他不动，球队输球了，他都不动」「今天有点外汇，明天粮食出问题，今天修复点财政，明天来个自然灾害」。
6. **对仗收句。** 「国家提供武装，资本控制产业，教会控制思想。」「卡比拉做面子，卢旺达军队做里子。」
7. **直接跟观众说话。** 「大家发现没有」「各位如果外派到乍得，千万别被账单给吓到」「观众里有没有学葡萄牙语的」「这个我们讲过，大家可以去考古」「下来大家有什么感觉？」
8. **坦白和自嘲。** 「我不是匈牙利历史学家……B 站上有很多账号做的内容更好」「反复删改，只能说给大家拿出来这样一个节目」「但我说实话」。→ 和林序「只是一个数码爱好者」的人设对得上
